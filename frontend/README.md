# LearnPulse frontend

The React/Vite interface for the local LearnPulse backend. From this directory run `npm install`, then `npm run dev`. The API defaults to `http://127.0.0.1:8000`; set `VITE_API_URL` to change it.

The four screens are Library, Study, Practice, and Progress. Their data flow is documented in the root `README.md` and `SPEC.md`.
